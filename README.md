# LEVEL 2.0

LEVEL помогает связать долгосрочные цели с ежедневными задачами, практикой и обучением. Новое пространство открывается без личных записей. Доступны локальный режим и вход в облачный аккаунт.

## Проверка и публикация

```sh
npm test
npm run build
```

Публикуется только содержимое `dist/`. GitHub Actions развёртывает его в GitHub Pages при обновлении `main`. Перед публикацией примените SQL из `supabase/migrations/` к проекту LEVEL. Миграция использует существующую таблицу `level_snapshots`, оставляет чтение под действующим RLS и направляет запись через RPC с проверкой владельца, версии и поколения данных. Прямые записи старого клиента после миграции отклоняются. Запуск браузерного сценария требует Playwright. См. `tests/browser.cjs`.

## Облачные данные и сброс

Гостевой режим хранит данные в браузере. Данные авторизованного пользователя загружаются с сервера и не копируются в общее гостевое хранилище. Если две вкладки сохранят одновременно, вторая получит конфликт. Она сможет скачать черновик и открыть текущую облачную версию. Загруженный файл можно импортировать только вручную.

В разделе «Профиль → Настройки» сброс требует скачать копию, выбрать тот же файл и ввести `СБРОСИТЬ`. Облачный сброс сверяет ревизию и SHA‑256, меняет поколение снимка, отзывает ключ интеграции и возвращает к первоначальной настройке. Раздел «Данные старой версии» экспортирует старый localStorage и файлы доказательств из IndexedDB на текущем устройстве. Очистка этого устройства доступна отдельно. Локальные файлы с другого устройства доступны в браузере, где они были добавлены.

Старый облачный снимок без сброса преобразуется при первом сохранении. Исходные поля остаются доступны в JSON-копии. После сброса старый клиент не имеет разрешения записать их обратно.

## Daily Review

«План → Обзор дня» принимает дневниковые записи и текстовые отчёты `.txt` и `.md`. Поле «Следующий шаг» даёт основание предложить новую задачу. Движок на правилах сверяет выполненные действия, открытые задачи, сроки целей и доступное время с учётом рабочих часов, сна и дней отдыха. Повторный запуск по тому же дню открывает сохранённый обзор. Настройка автоматического переноса затрагивает обычные задачи, которые помещаются в свободное время. Для изменения сроков целей и переноса важных задач требуется ручное решение. Обзор XP не начисляет.

При включении «Ночной обзор в облаке» pg_cron каждые 10 минут проверяет, готов ли обзор за предыдущую дату в часовом поясе аккаунта. Дневной обзор защищён транзакционной блокировкой и ключом даты в снимке. Неудачные запуски повторяются в течение следующего местного дня. Гостевой режим запускается вручную.

## Передача отчёта из внешнего AI

Для ChatGPT можно скопировать краткий дневной отчёт в дневник или импортировать текстовый файл. Для автоматической передачи в своём агенте добавьте следующий вызов. Уровень доступа ключа ограничен добавлением записей. LEVEL не запрашивает историю ChatGPT и сам не отправляет платные AI-запросы.

1. Откройте «Профиль → Настройки → Интеграция дневника» и выпустите ключ.
2. Сохраните его в хранилище секретов вашего агента. Передавайте только текст, на отправку которого пользователь согласился.
3. Выполните POST и сохраните тот же UUID `event_id` при повторной отправке события. `report_day` допускается опустить через `null`, тогда используется локальная дата LEVEL.

```http
POST https://vlbheybdqnddaxykalth.supabase.co/rest/v1/rpc/level_ingest
apikey: YOUR_SUPABASE_PUBLISHABLE_KEY
Content-Type: application/json

{
  "token": "YOUR_LEVEL_AGENT_KEY",
  "event_id": "7da06d27-d978-4511-8e31-05d9aae5aecd",
  "body": "Дневной отчёт пользователя",
  "report_day": null,
  "next_action": "Следующее конкретное действие",
  "minutes": 20
}
```

Публичный ключ Supabase указан в `app/cloud.js`. Ключ LEVEL можно заменить или отозвать из настроек. Ключ другого AI-провайдера хранится у внешнего агента. Стоимость и разрешение на запросы настраиваются там до запуска модели.

## Проверка результатов

Изучение материала отмечает пользователь. Практику можно завершить с описанием результата, а тест оценивает точный текстовый ответ без учёта регистра и пробелов по краям. XP каждого этапа начисляется один раз. Ранг навыка появляется при достижении заданного числового норматива и ручном подтверждении замера.
