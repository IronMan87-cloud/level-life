# LEVEL

Личная RPG-система для целей, ежедневных действий и развития навыков.

## Что уже есть
- Обзор дня, уровень и прогресс.
- Ежедневные задачи с приоритетами и привязкой к целям.
- Долгосрочные цели и ручное обновление прогресса.
- Независимые навыки и Proof of Skill с фиксацией измерений, тестов, документов, фото/видео и результатов проектов.
- Проекты.
- Учёт доходов и расходов.
- Экспорт и импорт резервной копии JSON.
- PWA-манифест и service worker для установки и офлайн-оболочки.

## Приватность
Это статическое приложение. Пользовательские записи хранятся в localStorage браузера на устройстве и не отправляются в этот репозиторий. Сам репозиторий публичный: не добавляйте сюда личные данные, пароли, токены или финансовые документы. Регулярно экспортируйте резервную копию из приложения.
